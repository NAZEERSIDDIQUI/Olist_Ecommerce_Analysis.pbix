#  E-CommerceAnalysis

## Project Overview

An interactive Power BI dashboard analyzing Brazilian e-commerce data from Olist.

The project focuses on sales performance, customer behavior, delivery performance, product categories, sellers, reviews, and payment methods.

## Tools & Technologies

- Power BI
- DAX
- Data Analysis
- Data Visualization
- Excel/CSV
- E-commerce Analytics

## Dashboard Pages

### 1. Executive Sales Dashboard
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Monthly Revenue Trend
- Product Category Analysis
- State Analysis
- Order Status Distribution

### 2. Customer & Operations Analysis
- Average Review Score
- Review Score Distribution
- Average Delivery Days
- Late Orders
- Payment Method Analysis

### 3. Product & Seller Analysis
- Top Product Categories
- Top Sellers
- Average Freight Cost
